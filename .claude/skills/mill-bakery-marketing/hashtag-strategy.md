# Hashtag + Caption Strategy (2026)

Based on current Instagram best practices and algorithm behavior. Update when Meta changes the rules again.

## Caption rules

1. **Hook in the first line.** First 125 characters show before "...more" — get the most important word/question/statement up front.
2. **Length sweet spot: 138–150 characters total** for feed posts. Educational/storytelling can go to 800+ but most of ours should be short.
3. **Structure:** `HOOK` → `1–2 sentence body` → `CTA` → blank line → hashtags
4. **Tone**: lowercase informal (see `brand-guide.md`). Use line breaks; nobody reads walls of text.
5. **CTA should ask for a specific action**: "Stop in this week", "Save this for tomorrow's coffee run", "Tell us your order in the comments".
6. **One emoji max per caption.** Acceptable: ☀️ ☕ 🥐 🍞.

## Hashtag rules

1. **Use 5–9 hashtags per post.** 3–5 if Meta recommendation; 7–9 still works if all are highly relevant. Never go over 12.
2. **Tier mix: 1-2-2-1 pattern**
   - **1 broad** (1M+ posts): `#panaderia`, `#pandulce`, `#breakfastburrito`
   - **2 niche** (50k–500k): `#mexicanbakery`, `#panaderiaartesanal`, `#mexicanbreakfast`, `#licuados`, `#conchas`
   - **2 community/local** (under 50k, intent-driven): `#santaanafood`, `#santaana`, `#downtownsantaana`, `#ocfoodie`, `#BestFoodOC`
   - **1 branded**: `#millbakery` — start using consistently so it builds equity
3. **Never copy-paste the exact same hashtag set across posts** — looks spammy. Rotate 30-50% per post.
4. **Place hashtags in the caption itself** (line break after CTA, then hashtags). First-comment hashtags no longer help in 2026.

## Accounts worth tagging (selectively)

- `@bestfoodoc` — for posts featuring specific menu items, occasional. Don't tag every post.
- `@visitsantaana` — for community/personality posts. Same caution.

Do NOT tag accounts the bakery isn't actually related to — feels spammy and Meta penalizes it.

## Location tagging

Always tag the location "Mill Bakery" in the Instagram app when uploading. The skill produces the PNG + caption; location goes in the IG interface itself.

## What to track

- Saves per post (algorithm reward signal)
- Shares per post (algorithm reward signal)
- Reach from hashtags (in Instagram insights, look at "from hashtags" breakdown)
- Comments — questions in captions invite these
- Profile visits and follows
